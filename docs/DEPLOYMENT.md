# انتشار نسخهٔ کامل

GitHub Pages فقط فایل‌های ایستا ارائه می‌کند و برای اجرای FastAPI و SQLite این پروژه مناسب نیست. فایل `render.yaml` سرویس Docker را برای Render، همراه با مسیر پایدار پایگاه داده و بررسی سلامت، تعریف می‌کند.

## راه‌اندازی

1. در [Render Dashboard](https://dashboard.render.com/) از مسیر **New > Blueprint** مخزن `HYaghoobi/my-project-1` را انتخاب کن.
2. فایل `render.yaml` را بررسی کن. این تنظیم یک سرویس وب و دیسک پایدار ۱ گیگابایتی می‌سازد. دیسک پایدار به طرح پولی نیاز دارد؛ پیش از تأیید، هزینهٔ روز را در Render بررسی کن.
3. هنگام ساخت Blueprint، مقدار `OPENROUTER_API_KEY` را در فرم امن Render وارد کن. کلید را در مخزن یا فایل کد قرار نده.
4. Blueprint را تأیید کن و منتظر پایان Deploy بمان. نشانی عمومی در صفحهٔ سرویس Render نمایش داده می‌شود.
5. مسیر `/api/health` را باز کن؛ پاسخ سالم باید `{"status":"ok"}` باشد. سپس با حساب آزمایشی `user` و `password` ورود و گفت‌وگوی دستیار را بررسی کن.
6. برای بررسی ماندگاری، یک تغییر در برد انجام بده، سرویس را مجدداً Deploy کن و مطمئن شو تغییر باقی مانده است.

## نکتهٔ دسترسی

حساب این نسخه آزمایشی و ثابت است؛ هر کسی که نشانی عمومی را بداند می‌تواند با `user` و `password` به برد مشترک وارد شود و آن را تغییر دهد. اطلاعات واقعی یا حساس را در آن قرار نده.
